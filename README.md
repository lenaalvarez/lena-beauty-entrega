# LENA BEAUTY – Proyecto Final Front-End

## Descripción

Lena Beauty es una tienda web de demostración dedicada a la venta de productos de belleza y cuidado personal. El proyecto presenta un catálogo de productos, recomendaciones obtenidas mediante una API externa y un carrito de compras interactivo.

El sitio cuenta con un diseño adaptable a distintos dispositivos y una interfaz pensada para ofrecer una experiencia de navegación sencilla.

## Tecnologías utilizadas

- **HTML5:** estructura semántica del sitio.
- **CSS3:** estilos, diseño visual y adaptación a diferentes tamaños de pantalla.
- **Bootstrap 5:** componentes y recursos para el diseño responsive.
- **JavaScript:** interactividad y manipulación del DOM.
- **Fetch API:** consulta de productos desde una API REST externa.
- **LocalStorage:** almacenamiento de los productos del carrito.
- **Formspree:** gestión del formulario de contacto.
- **Google Fonts:** tipografías utilizadas en el diseño.

## Funcionalidades

- Catálogo de productos de belleza y cuidado personal.
- Tarjetas de recomendaciones cargadas dinámicamente mediante Fetch API.
- Carrito de compras interactivo.
- Incorporación y eliminación de productos del carrito.
- Modificación de cantidades.
- Cálculo automático de subtotales y total.
- Contador dinámico de productos.
- Persistencia del carrito mediante LocalStorage.
- Simulación de compra.
- Formulario de contacto con validación.
- Sección multimedia con video incrustado.
- Diseño responsive para dispositivos móviles y computadoras.

## Estructura del proyecto

- `index.html`: estructura principal del sitio.
- `css/`: hojas de estilo.
- `img/`: imágenes utilizadas en el proyecto.
- `script.js`: funcionalidades e interactividad.
- `README.md`: documentación del proyecto.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` utilizando Live Server.
4. Contar con conexión a Internet para cargar los recursos externos y consultar la API.

## Recursos externos

- **API REST:** DummyJSON.
- **Formulario de contacto:** Formspree.
- **Video:** YouTube.
